# imersão_dados_alura
# 🎲 Dashboard de Salários na Área de Dados

Um dashboard interativo para explorar salários na área de dados ao longo dos anos. Feito com **Python**, **Streamlit**, **Pandas** e **Plotly**, ideal para quem quer analisar tendências salariais, cargos e tipos de contrato de forma prática e visual.

## Funcionalidades

- Filtrar dados por **ano**, **senioridade**, **tipo de contrato** e **tamanho da empresa**.
- Visualizar **salário médio**, **salário máximo**, **cargo mais frequente** e **total de registros**.
- Gráficos interativos:
  - Top 10 cargos por salário médio
  - Distribuição de salários anuais
  - Proporção de tipos de trabalho (remoto, híbrido, presencial)
  - Mapa de salário médio de Cientistas de Dados por país
- Tabela detalhada de todos os registros filtrados.

## Tecnologias

- Python
- Streamlit
- Pandas
- Plotly

## Como usar

1. Clone o repositório
3. Instale as dependências
